# Precomputed watermark demonstrations

Meeting Brief and Incident Handoff are original Skills written for public
demonstration. Each directory contains the original Markdown, the watermarked
Markdown, and the saved detection evidence. Their SHA-256 hashes are recorded
in `evidence.json`; retain the exact file bytes when verifying them.

The texts were generated using Qwen3-8B, reviewed, and editorially corrected
before final scoring. These curated examples are not an unbiased benchmark.
Skill execution was not tested. Nominal p-values are not calibrated production
false-positive rates; a detected signal does not by itself establish semantic
quality, functional equivalence, or ownership.

Website highlights show changed wording, not green-list token assignments.
Metrics always refer to the complete saved documents, including when a single
passage is selected. No inference or detection is performed in the browser.
